# 功能、Mock 与原需求边界

本快照面向可运行的本地演示，尚未完整满足原需求规格。源码公开、按钮存在和模拟数据展示都不能证明真实供应商接入、容量达标或公网部署完成。

## 当前可执行的功能

| 范围 | 实际行为 |
| --- | --- |
| 内容输入与推荐 | 原文输入、海报/公众号配图选择、类型及风格筛选、先分析后展示候选，用户手动绑定模板 |
| 模板 | 两类各六种风格，共 12 个当前版本；保留旧版本；缩略图由同一套服务端排版实际生成 |
| 字段与事实 | 六个字段编辑、原文/处理结果对照、逐字段保留或采用、缺失信息追问、逐项事实确认 |
| 草稿与恢复 | 新稿实时暂存在当前浏览器；保存/分析后进入服务端；已有任务自动同步；按身份与标签页保存离线副本；暂存不可用时明确提示，并区分服务端保存是否成功 |
| 生成任务 | 持久化文字/排版作业、真实进度与排队位置、关闭后重开恢复、完成消息与已读状态 |
| 图片素材 | JPG/PNG 解码验证、私有/公共素材、名称标签搜索、收藏、公共副本导入、缩略图和像素裁剪 |
| 排版调整 | 文字及图片区域选择、字号/字重/颜色/对齐/坐标、图片等比裁剪或留白；保存后重新确认生成 |
| 预览与导出 | 服务端真实预览、放大查看、PNG/JPG/PDF、1 倍或 2 倍像素；旧 revision 的预览不能作为当前版本下载；重新生成新版本后清除旧预览加载失败状态 |
| 历史作品 | 重命名、复制草稿、删除；检查资源归属、内容版本和生成忙状态 |
| 账号 | 开发验证码注册/找回密码、密码散列、登录限速、昵称、改密、退出和账号工作区 |
| 匿名导入 | 登录时默认不勾选导入；不导入时保留原匿名工作区，退出后返回；离线副本不会静默混入其他身份 |
| 角色与审核 | 普通用户、审核员、管理员；作者不能自审公共素材和模板；保护最后一位有效管理员 |
| 模板工作台 | 私有克隆、字段编辑、单层网格和合并跨度、试填图片、真实预览、版本冲突、提交/退回/批准和不可变发布 |
| 运行与数据 | 管理员诊断和运行模式选择、SQLite 与不可变图片备份、本地启动及生产配置示例 |

后端负责模板、字段、事实、图片和导出检查。文字作为转义后的文本排版，上传不接收用户 HTML、SVG 或远程图片 URL。

接口返回 HTML 或不完整 JSON 时，页面显示中文错误及可用的请求编号，便于检查服务状态。

## Mock 的具体含义

| 环节 | 默认行为 | 不能据此宣称 |
| --- | --- | --- |
| 文字处理 | 本地规则提取、推荐和缺失检查；不确定的信息保留原文并提示人工核对 | 已调用真实模型、具备通用语义理解或智能润色能力 |
| 文字生成图片 | 根据描述生成带标识的抽象占位图 | 已完成真实 AI 文生图 |
| 参考图片变体 | 简单颜色变体并标注 Mock | 已完成真实 AI 图生图 |
| 开发验证码 | 在开发页面显示验证码，便于演示注册和找回密码 | 已发送真实邮件或短信 |
| 排版和导出 | 使用实际图片、内嵌字体及 Chromium 生成文件 | PDF 是可编辑矢量，或 2 倍像素放大属于无损增强 |

真实文字服务与真实文生图已有后端适配及失败路径测试；没有真实供应商调用记录。real 模式缺少配置会明确报错，不会静默返回 Mock。真实图生图的供应商协议尚未确定。

## 与完整原需求仍有差距

- **外部服务和上线：** 没有真实文字/图片供应商、邮件/短信或公网部署的本次验收记录。生产手机号验证及真实图生图尚未接通。
- **作品类型：** 目前只有海报和公众号配图，邀请函、期刊的独立模板体系尚未实现。多页项目后端已提供（手动加页、逐页生成、多页栅格 PDF，见 [多页说明](MULTIPAGE.md)），前端多页编辑待接入；不支持自动拆页和可编辑 PPTX。
- **编辑能力：** 支持对象选择与数字坐标、单层网格和合并跨度；尚无任意自由画布、拖拽吸附、嵌套网格或局部涂抹重绘。
- **数据与个人资料：** 未保存的新稿不能自动跨设备同步；完整个人资料项、素材删除清理、审核消息通知、原图与压缩预览分级仍需补齐。
- **图片任务恢复：** 图片生成有并发和等待上限，尚未纳入可跨进程重启恢复的持久作业；文字与排版作业已经持久化。
- **事实与内容理解：** 保守规则和人工确认不等于通用实体识别。无法可靠理解的含事实句会保留原文，Mock 不执行真实语义润色或智能压缩。
- **输出质量：** PDF 是当前预览的单页栅格封装，尚无可编辑矢量、印刷色彩管理或无损增强。
- **容量与兼容：** 单机 SQLite 和本地文件不等于云存储。原需求中的 10000 用户、100 GB、500 在线、100 并发及响应时间指标尚无负载验收；Chromium 和移动视口检查不能代替 Chrome、Edge、Firefox 全套验收。
